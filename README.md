# Pocket Quest

Contoh aplikasi Android **money manager** berbasis *digital envelope budgeting* dengan elemen gamifikasi. Proyek ini dapat langsung dibuka dari Android Studio melalui **Open** pada folder root proyek.

## Yang sudah tersedia

- Dashboard saldo, penggunaan anggaran, XP, dan streak.
- Amplop digital untuk kategori Makan, Transportasi, Hiburan, dan Tabungan.
- Pencatatan pengeluaran melalui tombol **Transaksi**.
- Quest harian/mingguan, progress, dan reward visual.
- Halaman profil serta navigasi bawah.

## Menjalankan

1. Buka folder ini di Android Studio.
2. Pastikan Android SDK API 35 dan JDK 17 tersedia pada Android Studio.
3. Tunggu Gradle sync selesai, lalu pilih perangkat/emulator dan tekan **Run**.

Semua UI demo berada pada `app/src/main/java/com/pocketquest/MainActivity.kt`, sehingga mudah diubah dan dikembangkan lebih lanjut.
